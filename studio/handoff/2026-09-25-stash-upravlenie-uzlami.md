## Проверено на устройстве (Stash 3.4.1)

ST18 (24.09, 4 прогона): select переключается PUT'ом (38–122 мс), кириллица
проходит, чужое имя — 400 без сбоя выбора; fallback закрепляется PUT'ом;
`DELETE /proxies/{группа}` — 405; поля `fixed` нет.

ST19 (25.09, 05:45–11:25, ~70 прогонов cron, выгрузки в чате):
- Закрепление fallback (здоровый член и мёртвый муляж) и url-test: встало,
  но к следующему удачному чтению (через 25 мин) сброшено на автовыбор.
  ПРИЧИНА НЕ УСТАНОВЛЕНА: в этом окне сеть сменилась Wi-Fi → сотовая, а
  контроллер ~20 мин не отвечал (возможен перезапуск ядра). Одиночный опыт.
- load-balance: PUT → 400 `must be one of Selector / URLTest / Fallback`.
- Выбор в select держится часами (≥5 ч).
- ОБЁРТКА РАБОТАЕТ: fallback над ручным select пропускает его при мёртвом
  выборе (≤25 мин) и возвращается к нему при живом (≤20 мин). Разрешение по
  времени грубое — ограничено частотой удачных чтений, не Stash.
- Тип сети читается по `now` группы RH-AI (RH-AI-W / RH-AI-C).
- Ручной выбор в группе с ssid-policy: вывода нет (совпал со значением политики).
- Контроллер недоступен (EOF / тайм-аут прогрева, повтор через 1 с не спасает)
  примерно в 30 % прогонов, окна до 17–20 мин.
- Карта рычагов: `GET /connections/{id}` → 200 (DELETE по id не проверен);
  `/group`, `/group/{имя}/delay`, `/dns/query` — маршрутов нет;
  `/proxies/DIRECT/delay` работает; маршруты `/providers/proxies/{имя}` (GET,
  PUT, healthcheck) есть; `/providers/proxies` пуст (поставщиков нет);
  `/logs` — поток, за 3 с данных нет. `$httpClient` умеет get/post/put/patch/
  delete/head/options; в `$environment` сведений о сети нет.
- ПЕРЕХВАТЧИК ССЫЛКИ РАБОТАЕТ (25.09, 11:31, 4 нажатия в Safari): переход на
  `http://rh-cmd.example.net/st19?n=…` перехвачен request-скриптом, PUT 204,
  выбор RH-Т19-Команда сменился и сверен чтением — все 4 раза, ~1 с на
  нажатие. В контексте request-скрипта есть `$request` и `$httpClient`.
  Значит, страница по https может командовать Stash обычными ссылками — без
  токена на телефоне и без MITM. Для боевой панели нужны белый список групп
  «-Ручной», узлы без обхода и защита от чужих ссылок (одноразовый токен /
  подтверждение). Открывает ли уведомление ссылку из опции `url` — неизвестно.
