# Авто-память Claude Code

Заметки, которые Claude Code ведёт сам (поправки Дианы, предпочтения, решения по проекту). Хранятся здесь, а не в контейнере, чтобы не пропадать вместе с облачной сессией (`autoMemoryDirectory` в `.claude/settings.json`). Коммитятся вместе с работой; править и удалять можно как обычные файлы.
