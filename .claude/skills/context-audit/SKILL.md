# Аудит контекста

ЗАЧЕМ. Коннекторы, плагины и скиллы занимают контекст до первого слова
Дианы, и этот объём повторяется в каждом запросе сессии. Чем его меньше, тем
позже сработает монитор (`.claude/hooks/context-watch.js`) и тем реже нужна
передача дел. Хук `SessionStart` напоминает вызвать этот скилл в новой
сессии; в той же сессии повторно не вызывать.

## Порядок

1. **Опись — только по тому, что видно у себя** (системный промпт,
   напоминания, список скиллов, список отложенных инструментов). Не
   выдумывать чисел.
   - MCP-серверы: имя и число инструментов (по префиксу `mcp__<сервер>__`).
     Отложенные инструменты занимают контекст только именем, пока схема не
     загружена (code.claude.com/docs/en/costs#reduce-mcp-server-overhead),
     но инструкции серверов входят целиком — отметить длинные.
   - Скиллы: сколько и из каких плагинов (префикс `<плагин>:`).
   - Субагенты `.claude/agents/`, `CLAUDE.md`, память проекта.
2. **Точная цифра.** После первого ответа монитор сообщит «базовый объём
   сессии» — входные токены первого ответа. Если строка уже пришла — дать
   её в отчёте; если нет — написать, что придёт после первого вызова
   инструмента. Разбивку по категориям видит только Диана: один раз
   попросить `/context`, если без точных чисел решение не принять.
3. **Под текущую задачу** (первый запрос Дианы) — что нужно, что лишнее:

   | Задача | Нужно | Обычно лишнее |
   |---|---|---|
   | Worker, конфиг, скрипты, тесты | GitHub MCP, `engineering` | `design`, `document-skills`, Dropbox, Drive, Kernel |
   | D1, замеры | Cloudflare MCP, `data` | `design`, `document-skills` |
   | Панель, дашборд | `modern-web-guidance`, `design` | `data`, `document-skills` |
   | Документы репозитория | GitHub MCP, `engineering:documentation` | Cloudflare, `design`, `data` |

4. **Что сделать самому.** Синхронизированный с claude.ai плагин, лишний
   для репозитория целиком, отключается в `.claude/settings.json`:
   `"enabledPlugins": { "<имя>@synced": false }`
   (code.claude.com/docs/en/plugins-reference#synced-plugins). Это правка
   репозитория: ветка → PR → Merge Дианы; не делать без её «да» в этой
   сессии. Плагин, нужный в других задачах, не отключать — только сказать.
5. **Что сказать Диане.** Коннекторы (MCP) и плагины всего аккаунта
   выключает она сама: приложение Claude → **Customize** в боковой панели →
   коннекторы / плагины (code.claude.com/docs/en/desktop#extend-claude-code;
   путь в веб-версии claude.ai документацией не подтверждён). Обязательные
   плагины организации выключить нельзя.

## Отчёт

Таблица не длиннее 10 строк: «что | сколько | нужно для задачи? | действие
(сам / Диана / оставить)». Под ней одна строка: базовый объём или «придёт
после первого вызова инструмента». Затем — ответ на запрос Дианы.
